# BTGKMB

Native Android food-management application for the BIT240102 Food Manager
project.

- **Project source:** [BIT240102_FoodManager](./BIT240102_FoodManager/)
- **Build and MockAPI setup:** [project README](./BIT240102_FoodManager/README.md)

- **Technology:** Kotlin, Jetpack Compose, Room, Retrofit, and WorkManager.

See the project README for prerequisites, build instructions, offline
synchronization, and the small-commit GitHub submission guide.
